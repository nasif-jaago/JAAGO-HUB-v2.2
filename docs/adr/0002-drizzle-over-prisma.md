# ADR 0002: Drizzle ORM over Prisma

## Status
Accepted

## Context
The ERP database layer must handle high-concurrency transactions, dynamic multi-tenant Row-Level Security (RLS) session variables, millions of future records, time-partitioned tables, and custom database migrations generated by the module system without engine bloat or cold-start latency.

## Decision
We select **Drizzle ORM** over Prisma for all database operations across JAAGO HUB.

## Rationale & Consequences
- **Zero Binary Engine**: Drizzle executes as pure TypeScript directly over `postgres.js` / node-postgres, avoiding Prisma's heavy Rust query engine binaries and memory overhead.
- **SQL Dialect Transparency**: Drizzle provides full access to native PostgreSQL features (BRIN indexes, partial indexes, generated columns, table partitioning, and `SET LOCAL` RLS tenant context).
- **Module System Compatibility**: Enables compile-time and runtime modular schema stitching, which is critical for Odoo-style module inheritance and extensions.
